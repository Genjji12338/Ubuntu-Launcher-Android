# Yaru Home

Ein Android-Launcher, der den Homescreen im Ubuntu-/Yaru-Design darstellt.

## Features
- Ubuntu-/Yaru-inspirierte Oberfläche als Homescreen-Ersatz
- App-Übersicht, die sich bei Installation und Deinstallation automatisch aktualisiert
- Eigenes Power-Menü (über einen Bedienungshilfen-Dienst)
- Benachrichtigungsanzeige (über einen Benachrichtigungs-Dienst)

## Technik
- Kotlin, Jetpack Compose
- Room (lokale Datenbank), DataStore (Einstellungen)
- Min. Android 8.0 (API 26), Target Android 15 (API 35)

## Installation
1. APK unter *Releases* herunterladen
2. Installation aus unbekannten Quellen erlauben
3. Yaru Home als Standard-Launcher festlegen
4. Bedienungshilfe und Benachrichtigungszugriff in den Einstellungen freigeben
